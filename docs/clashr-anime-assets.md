## Contract address field

Landing and token-status pages use `NEXT_PUBLIC_CLASHR_TOKEN_ADDRESS`. Leave it blank before launch: the field reads CA coming soon and copy is disabled. After verifying the deployed BNB token, configure the address and rebuild the web app. The field displays the checksum address and enables Copy CA. Invalid, zero and incorrect mixed-case checksum addresses remain unpublished. This setting does not deploy or verify a token on-chain.
